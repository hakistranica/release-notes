# Светът на Хаки — какво е ново

Public release notes (Bulgarian) of the "Светът на Хаки" website, with their screenshots:
https://hakistranica.github.io/release-notes/

This repository is **generated** by `scripts/publish-release-notes.mjs` in the private project
repository (`hakistranica/stunning-fiesta`) after each release. Do not edit it by hand: the next
publish overwrites the release folder and the site files. The pages are marked `noindex`.
